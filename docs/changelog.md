# 变更记录

## 2026-10-23

### 新增

- 为需要真实解析的境外域名增加 DoH 回退策略，保留国内解析和独立的节点域名解析；境外 DoH 通过自动兜底组转发。
- 增加香港、新加坡、日本、台湾、美国之间的自动兜底，作为 Manual 和链式入口的首选候选。

### 变更

- 地区组健康检查周期由 300 秒调整为 120 秒，增加 50 毫秒切换容差并关闭懒惰测试。
- 订阅集和静态 SOCKS5 的测速目标统一为 Google 的 HTTP 204 地址，保留 5 秒超时和每日订阅更新周期。
- 补充已有设备需手动选择自动兜底、覆写数组合并方式以及验证范围说明。

### 兼容性

- 保留现有 Fake-IP 过滤、业务规则和私密凭据分离方式，AI 与社交的最终静态 IP 出口不变。
- 本次配置未热加载到 Apple TV；跨地区切换和 Stash 内置 DNS 的运行效果需要更新配置后验证。
